本アプリの聴診音はすべて Web Audio API によるリアルタイム音響合成であり、実録音ではありません。 心音・肺音・腸雑音・血管雑音の音響学的パラメータ（周波数帯域・持続時間・包絡線形状）は 公表文献の代表値に基づく近似モデルです。教育目的の合成音であり、実機聴診の代替にはなりません。 採点はキーワードベースの部分点評価で、AIによる自由記述判定は行っていません。
